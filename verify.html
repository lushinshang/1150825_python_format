雜湊驗證工具

選一個檔案，瀏覽器用內建的 Web Crypto API 直接在本機算出 sha256，不會把檔案內容送到任何地方。
可以拿來核對下載的 python_format.html 有沒有跟官方版本一致。

📄
點這裡選檔案，或把檔案拖進來
整個過程都在瀏覽器本機執行，離線也能用
計算中…
—
這個工具能防什麼、不能防什麼
能核對「拿到的檔案內容」是否跟「你信任的來源公布的雜湊值」一致——可以抓到下載過程損毀、或檔案被中途動過手腳。但如果你貼進來比對的雜湊值本身來源就不可信（例如也是從同一個被竄改的地方拿到的），這個工具沒辦法幫你分辨。建議雜湊值優先從 首頁 上顯示的內容核對，或直接看 repo 裡的 python_format.html.sha256。
